# OCR v11 — Receipt reading update

این نسخه بر پایه v10 ساخته شده و همه فایل‌های قبلی پروژه را حفظ می‌کند.

## تغییرات OCR
- حالت پیش‌فرض سریع: فقط شماره پیگیری/رهگیری/مرجع/سند
- تشخیص چند برچسب بانکی و برگرداندن چند کاندید برای انتخاب دستی
- نرمال‌سازی اعداد فارسی و عربی
- Retry واقعی: نتیجه قبلی به مدل ارسال نمی‌شود
- Retry جداگانه برای هر فیلد در حالت «خواندن کامل»
- حالت «خواندن کامل رسید» به صورت اختیاری
- تیک انتخاب کنار هر فیلد
- ویرایش هر فیلد
- انتخاب دستی بین شماره‌های پیدا شده
- نمایش جزئیات کامل اطلاعات ذخیره‌شده رسید در تراکنش
- تلاش برای عدم حدس‌زدن ارقام مبهم با confidence/evidence

## Render
این متغیرها باید در Render باقی بمانند:
- OPENAI_API_KEY
- OPENAI_VISION_MODEL=gpt-5.4-mini
- VITE_SUPABASE_URL
- VITE_SUPABASE_ANON_KEY

کلید OpenAI را داخل GitHub یا فایل .env واقعی قرار نده.
